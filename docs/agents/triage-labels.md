# Triage labels

The engineering skills use five canonical triage roles. This table maps each role to its GitHub label.

| Skill role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer must evaluate the issue. |
| `needs-info` | `needs-info` | The issue needs more information from its reporter. |
| `ready-for-agent` | `ready-for-agent` | The issue is specified and ready for an unattended agent. |
| `ready-for-human` | `ready-for-human` | The issue needs human implementation or judgment. |
| `wontfix` | `wontfix` | The maintainers will not act on the issue. |

When a skill names a role, use the matching label from this table.
